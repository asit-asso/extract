Description

The e-mail notification plugin sends a customized message to one or more recipients.

Recipient e-mail addresses must be separated by semicolons. To notify the client of the request, use the {clientEmail} placeholder as a recipient e-mail address.

Available placeholders

The subject and content of the message can contain placeholders that will be replaced with values from the request. Use the {fieldName} syntax with curly braces.

Basic information
  • {orderLabel} - Order/request name
  • {productLabel} - Product name
  • {startDate} - Submission date (formatted, e.g. "Oct 27, 2025 2:30:00 PM")
  • {startDateISO} - Submission date (ISO 8601 format, e.g. "2025-10-27T14:30:00Z")
  • {endDate} - End date (formatted)
  • {endDateISO} - End date (ISO 8601 format)
  • {status} - Request status (ONGOING, FINISHED, ERROR, etc.)
  • {rejected} - Boolean, true if the request was rejected
Client and organization
  • {client} or {clientName} - Client name
  • {clientEmail} - Client's e-mail address (can be used as a recipient)
  • {clientGuid} - Client's unique identifier
  • {organism} or {organisationName} - Client's organization name
  • {organismGuid} - Organization's unique identifier
Third party
  • {tiers} - Third-party organization name (can be empty)
Geographic information
  • {perimeter} - Geographic perimeter (WKT format)
  • {surface} - Order surface area
Remarks
  • {remark} - Client's remark/comment
Dynamic parameters

The request's JSON parameters are accessible in two ways:

  • {parameters.KEY_NAME} - Access by key name (case-sensitive)
    Example: {parameters.FORMAT} to access the "FORMAT" key
  • {param_KEY_NAME} - Alternative notation (case-sensitive)
    Example: {param_FORMAT} to access the "FORMAT" key

Important note:

  • Missing standard field placeholders ({client}, {orderLabel}, etc.) are replaced with an empty string
  • Non-existent dynamic parameters ({parameters.XXX}, {param_XXX}) are replaced with the string "null"
  • The e-mail will always be sent, even if some placeholders are missing

Examples

Subject example:

New request for product {productLabel}, client {client}

Content example:

Hello,

Client {client} from organization {organism} ordered product {productLabel}.

Order details:
- Order number: {orderLabel}
- Processing date: {startDate}
- Surface area: {surface} m²
- Requested format: {parameters.FORMAT}
- Remark: {remark}

Best regards

Example with conditional parameters:

If a parameter may be absent, you can use HTML for conditional display:

<p>Client: {client}</p>
<p>Organization: {organism}</p>
<!-- The "raison" parameter can be empty if absent -->
<p>Reason: {parameters.raison}</p>
